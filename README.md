# 本地端歷史萬年曆 (Perpetual Calendar)

本專案為一款適用於**電腦（桌面瀏覽器）與手機（行動裝置／PWA）**的完全離線端歷史萬年曆查詢工具。系統以西元（公曆）日曆網格瀏覽為主、快速搜尋為輔，整合農曆、歲次干支、二十四節氣，並精確對照清朝帝號、臺灣日治時期帝號、民國及民國前紀年。

---

## 核心規格與特點

1. **跨度 400 年（西元 1726 年至 2126 年）**
   - 涵蓋清雍正四年至未來的百年天文預測。
   - 歷法與帝號標準對齊[中央研究院 兩千年中西曆轉換系統 (Sinocal)](https://sinocal.sinica.edu.tw/)。
2. **多維歷史紀年精確對照**
   - **清朝帝號**：收錄清世宗（雍正）至清遜帝（宣統）之朝代、廟號、年號與踰年改元對應。
   - **臺灣日治時期帝號**：收錄明治、大正、昭和之在位與即日改元，包含同日改元（如 1912/07/30 明治轉大正、1926/12/25 大正轉昭和）及 1895 乙未割臺、1945 光復等歷史界標。
   - **民國與民國前（民前）**：西元 1912 年為民國元年，1911 年及以前自動精確對照「民國前 N 年」（便利族譜、戶籍除戶簿考據）。
3. **二十四節氣精確標註**
   - 採用清代以來的「定氣法」（視黃經每 15 度為一節氣），日曆單元格標籤顯示交節日，詳細資訊卡提供時與分。
4. **離線優先（Offline-First）與跨平台**
   - 無需後端伺服器，不依賴外部網路連線，資料與演算法完全於本機端執行。
   - 支援響應式設計（RWD），手機單手觸控友善，桌面端具備寬螢幕高資訊密度卡片。

## 快速上手與部署（規劃）

本專案採現代純前端單頁架構（Vanilla HTML5 / CSS3 / ES Modules 或輕量打包）：
- **桌面端**：瀏覽器直接開啟 `index.html` 即開即用。
- **行動端**：支援 PWA（Progressive Web App），可「加入主畫面」離線執行。

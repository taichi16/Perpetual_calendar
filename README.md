# 本地端歷史萬年曆 (Perpetual Calendar 1726–2126)

本專案為一款跨度達 **400 年（西元 1726 年至 2126 年）** 的高精度**本地端歷史萬年曆**，適用於電腦（Windows / macOS 桌面瀏覽器）與行動裝置（iPhone / Android）。

系統以西元（公曆）日曆網格瀏覽為主、智慧搜尋跳轉為輔，整合農曆、歲次干支、二十四節氣（定氣法 UTC+8），並嚴格精確對照清朝帝號、臺灣日治時期帝號、民國及民國前（民前）歷史紀年。全介面堅持 **100% 正體繁體中文**，完全具備**離線優先（Offline-First）**特性。

---

## 🌟 核心規格與特色

1. **跨度 400 年歷史考據（1726 – 2126）**
   - 涵蓋清世宗雍正四年至未來的百年天文預測。
   - 歷法與帝號標準對齊[中央研究院 兩千年中西曆轉換系統 (Sinocal)](https://sinocal.sinica.edu.tw/)與日本內閣府改元公報。
2. **多維歷史紀年精確對照**
   - **清朝帝號（踰年改元）**：收錄清世宗（雍正）至清遜帝（宣統）之朝代、廟號、年號，落實正月初一日新元交接。
   - **臺灣日治時期帝號（即日改元）**：
     - `1895-05-23` 乙未割臺期標記交接過渡，並列光緒 21 年與明治 28 年。
     - `1912-07-30` **明治 45 年／大正元年（同日改元）**。
     - `1926-12-25` **大正 15 年／昭和元年（同日改元）**。
     - `1945-10-25` 臺灣光復受降典禮，五十年日治正式終止。
   - **民國與民國前（民前）精算**：
     - 西元 1912 年為民國元年（$\text{民國} = Y - 1911$）。
     - 1911 年及以前自動精算「民國前 N 年」（$\text{民國前} = 1912 - Y$），便利族譜與戶籍除戶簿考據。
     - **退位重疊期（1912-01-01 至 1912-02-12）**：民國元年成立但清帝尚未退位，並列清晰呈現。
3. **二十四節氣精確定氣時刻**
   - 採用「定氣法」（太陽視黃經每 15 度為一節氣，UTC+8 時區）。
   - 日曆單元格標籤標註交節日，詳細資訊卡提供小時與分鐘（如 2026 年春分為 `2026-03-20 22:45:59`）。
4. **純粹正體繁體中文**
   - 十二生肖（鼠、牛、虎、兔、**龍**、蛇、**馬**、羊、猴、**雞**、狗、**豬**）、節氣（**驚蟄**、**穀雨**、**小滿**、**芒種**、**處暑**）及農曆月份全面過濾為正體中文。
5. **離線優先與 PWA 支援**
   - 零後端伺服器相依，無外部 API 網路請求。
   - 支援安裝為獨立桌面軟體或手機 App。

## 📱 正式使用與安裝方式

本系統提供兩種使用方式：**免安裝線上版（可加入手機主畫面）** 與 **純本機離線版**。

### 方式一：線上存取與 PWA 安裝（推薦，手機與電腦通用）

#### 1. 啟用 GitHub Pages（倉儲擁有者設定）
1. 進入倉儲設定頁面：[Settings ➔ Pages](https://github.com/taichi16/Perpetual_calendar/settings/pages)
2. 在 **Build and deployment** 下：
   - **Source**：選擇 `Deploy from a branch`
   - **Branch**：選擇 `main`，目錄選擇 `/(root)`，按下 **Save**
3. 約 1 分鐘後即可使用專屬網址存取：  
   👉 **`https://taichi16.github.io/Perpetual_calendar/`**

#### 2. 在手機上安裝為 App（iPhone / Android）
- **iPhone (iOS)**：
  1. 以 **Safari** 開啟上述網址。
  2. 點擊螢幕下方「分享」按鈕（向上箭頭方框）。
  3. 下滑點選 **「加入主畫面」(Add to Home Screen)** ➔ 點擊右上角「新增」。
  4. 手機桌面上即會生成「**萬年曆**」專屬圖示，點開即可全螢幕獨立運行，即使無網路亦能離線查詢。
- **Android**：
  1. 以 **Chrome** 開啟上述網址。
  2. 點擊右上角「⋮」選單按鈕。
  3. 點選 **「加到主螢幕」** 或 **「安裝應用程式」**。

#### 3. 在電腦上安裝為桌面軟體（Windows / macOS）
1. 以 **Google Chrome** 或 **Microsoft Edge** 開啟上述網址。
2. 網址列右側會出現 **「安裝 歷史萬年曆」** 圖示（或至瀏覽器選單點選「安裝」）。
3. 點擊安裝後，系統即會在桌面與應用程式清單建立獨立圖示，開啟時為無網址列的獨立軟體視窗。

---

### 方式二：純本機檔案開啟（不需任何網路與伺服器）

- **macOS**：在 Finder 中進入專案資料夾，直接雙擊 `index.html`，以 Chrome、Safari 或 Firefox 開啟。
- **Windows**：在檔案總管中雙擊 `index.html`，以 Edge 或 Chrome 開啟。
- 專案底層已徹底解決本地 `file://` 協議之限制，**本機雙擊即開即用，無需搭建 HTTP 伺服器**。

## 💻 本地開發與架構說明

### 檔案結構

```
Perpetual_calendar/
├── index.html              # 萬年曆主頁面（語義化 HTML5、SEO、PWA 配置）
├── manifest.json           # PWA 應用程式清單（定義名稱、圖示、色彩）
├── sw.js                   # Service Worker 離線快取服務
├── css/
│   └── style.css           # 東方古典雅緻設計系統（宣紙暖白/幽玄水墨深色模式、硃砂紅印章）
├── js/
│   ├── main.js             # 應用核心自包含主腳本（相容 file:// 與 http://，含 100% 正體繁體轉換字典）
│   ├── lunar.js            # 壽星天文曆底層運算核心（定朔、定氣推算，零外部依賴）
│   ├── lunar-calc.js       # 農曆、二十四節氣（UTC+8）、歲次干支與十二生肖模組
│   ├── era-data.js         # 清朝帝號、日治帝號、民國紀年與歷史重大事件資料庫
│   ├── era-service.js      # 紀年查詢與同日改元、踰年改元邊界邏輯處理器
│   ├── calendar-core.js    # 公曆月曆計算、網格生成與狀態管理 (1726-2126)
│   └── search-service.js   # 快速智慧搜尋跳轉引擎（支援年號、民國、公曆、節氣、事件）
└── test/
    ├── test-cases.js       # TC-01 至 TC-06 自動化單元測試（Node.js 命令列執行）
    └── runner.html         # 瀏覽器端可視化測試報告執行器
```

### 本地開發伺服器（可選）

若您在開發過程中需要模擬 HTTP 伺服器環境，可於專案目錄執行：

```bash
# 使用 Python 3
python3 -m http.server 8088

# 或使用 Node.js npx serve
npx -y serve . -p 8088
```
瀏覽器訪問 `http://localhost:8088/` 即可進行調試。

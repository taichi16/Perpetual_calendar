# 本地端歷史萬年曆 (Perpetual Calendar 1726–2126)

本專案為一款適用於**電腦（Windows / macOS 桌面瀏覽器）與手機（行動裝置／PWA）**的完全離線端歷史萬年曆查詢工具。系統以西元（公曆）日曆網格瀏覽為主、快速智慧搜尋為輔，整合農曆、歲次干支、二十四節氣（定氣法 UTC+8），並精確對照清朝帝號、臺灣日治時期帝號、民國及民國前紀年。

---

## 核心規格與特色

1. **跨度 400 年（西元 1726 年至 2126 年）**
   - 涵蓋清雍正四年至未來的百年天文預測。
   - 歷法與帝號標準對齊[中央研究院 兩千年中西曆轉換系統 (Sinocal)](https://sinocal.sinica.edu.tw/)與日本內閣府改元公報。
2. **多維歷史紀年精確對照**
   - **清朝帝號（踰年改元）**：收錄清世宗（雍正）至清遜帝（宣統）之朝代、廟號、年號與踰年改元對應（正月初一改元）。
   - **臺灣日治時期帝號（即日改元）**：收錄明治、大正、昭和之在位與即日改元，包含同日改元（如 `1912/07/30` 明治轉大正、`1926/12/25` 大正轉昭和）及 1895 乙未割臺、1945 光復等歷史界標。
   - **民國與民國前（民前）**：西元 1912 年為民國元年，1911 年及以前自動精確對照「民國前 N 年」（便利族譜、戶籍除戶簿考據）。
   - **清帝退位過渡期**：1912-01-01 至 1912-02-12 宣統帝頒布退位詔書前，並列呈現民國元年與清宣統三年。
3. **二十四節氣精確標註**
   - 採用清代以來的「定氣法」（視黃經每 15 度為一節氣），日曆單元格標籤顯示交節日，詳細資訊卡提供時與分。
4. **離線優先（Offline-First）與跨平台**
   - 無需後端伺服器，不依賴外部網路連線，純前端（HTML5 / CSS3 / ES Modules）本機端直接執行。
   - 支援響應式設計（RWD），手機單手觸控友善，桌面端具備寬螢幕高資訊密度卡片。
   - 支援 PWA，可在 Windows / macOS 上「安裝為應用程式」或「新增至主畫面」。

## 檔案結構

```
Perpetual_calendar/
├── index.html              # 萬年曆主頁面（語義化 HTML5、SEO、PWA 配置）
├── manifest.json           # PWA 應用程式清單
├── sw.js                   # Service Worker 離線快取
├── css/
│   └── style.css           # 東方古典雅緻設計系統（宣紙暖白/墨黑深色模式、硃砂紅印章標籤）
├── js/
│   ├── lunar.js            # 高精度天文農曆底層運算庫（壽星天文曆核心，無外部相依）
│   ├── lunar-calc.js       # 農曆、二十四節氣（定氣法 UTC+8）、歲次干支與生肖推算
│   ├── era-data.js         # 清朝帝號、日治帝號、民國年號與歷史重大事件資料庫
│   ├── era-service.js      # 紀年查詢與同日改元、踰年改元邊界邏輯處理器
│   ├── calendar-core.js    # 公曆月曆計算、網格生成與狀態管理 (1726-2126)
│   ├── search-service.js   # 快速智慧搜尋跳轉引擎（支援年號、民國、公曆、節氣、事件）
│   └── app.js              # 主入口與 UI 互動控制器
└── test/
    ├── test-cases.js       # TC-01 至 TC-06 自動化單元測試（Node.js 執行）
    └── runner.html         # 瀏覽器端可視化測試報告執行器
```

---

## 快速使用方式

### 1. 本地直接執行（Windows / macOS 通用）
無需安裝 Node.js、Python 或任何伺服器環境：
- 雙擊開啟 `index.html` 即開即用。
- 點擊右上角「主題」可隨時切換深色（幽玄墨玉風）或淺色（宣紙書香風）。
- 鍵盤快速鍵：方向鍵 `←` / `→` 切換月份，`↑` / `↓` 切換年份。

### 2. 執行驗收測試 (TC-01 至 TC-06)
- **Node.js 命令列測試**：
  ```bash
  node test/test-cases.js
  ```
- **瀏覽器端可視化測試**：
  在瀏覽器中開啟 `test/runner.html` 即可檢視 6 組測試報告。

ℹ️ 關於萬年曆

📖 使用方式

  • 日期瀏覽與翻閱：點選日曆任一日期即可即時檢視歷史詳細紀年；亦可使用「上年 / 上月 / 下月 / 下年」按鈕或鍵盤方向鍵（↑ / ↓ 換年、← / → 換月）自由翻閱。
  • 年月直達跳轉：可透過月曆工具列的「年份」與「月份」下拉選單直達指定時間，或隨時點擊「今日」按鈕回到當天。
  • 智慧歷史搜尋：支援頂部搜尋欄輸入清代年號（如：光緒21、乾隆元年）、日治年號（如：明治28、昭和15）、民國紀年（如：民國前17、民國115）、西元日期（如：1895-05-23）或二十四節氣名稱（如：春分、冬至）進行快速精準定位。
  • 多維紀年對照：涵蓋西元公曆、農曆陰陽曆、清朝帝號年號（踰年改元考據）、臺灣日治時期帝號（即日改元精確標註）、民國與民國前紀年、干支歲次及二十四節氣精確交節時刻。
  • 深淺主題：點擊「主題」按鈕可隨時切換現代深色夜間模式與典雅淺色古風模式，系統自動記憶個人喜好。

🛠️ 開發工具與技術

  • 前端核心技術：原生 HTML5、Vanilla CSS3（CSS 自訂變數、CSS Grid、Flexbox 響應式排版）、現代原生 JavaScript (ES6+)。
  • 完全離線優先架構：零外部第三方網路依賴、純本地端天文數學演算法即時算力；支援 PWA（Progressive Web App）離線快取機制與本機雙擊開啟（相容 file:// 協議與 http:// 本地伺服器）。
  • 天文歷法演算法：採用天文高精度定氣法計算二十四節氣太陽黃經（精確至分秒）、六十干支週期循環演算法、嚴格對齊中央研究院《兩千年中西曆轉換》(Sinocal) 歷法規範。
